# Чекер даты регистрации аккаунта Discord по его ID

## Как посмотреть Discord ID
Необходимо включить режим разработчика и скопировать ID из профиля

Подробнее здесь: https://support.discord.com/hc/en-us/articles/206346498-Where-can-I-find-my-User-Server-Message-ID


## Запуск
В файл id.txt вставляем построчно ID наших аккаунтов

`python main.py` - запуск софта

Софт отобразит в консоли подробную информацию о дате регистрации для каждого ID, а также построчно запишет дату в формате "день.месяц.год" в файл results.txt
